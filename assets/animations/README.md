# 애니메이션 파일 저장 위치

이 폴더에 Lottie JSON 파일을 저장하세요.

## 사용 방법

1. [LottieFiles](https://lottiefiles.com)에서 원하는 애니메이션 다운로드
2. JSON 파일을 이 폴더에 복사
   - 예: `character_idle.json`
   - 예: `character_celebration.json`
3. `character_screen.dart`에서 파일 경로 수정

## 추천 검색어

- "character idle"
- "character walk"
- "character celebration"
- "character happy"
- "character sleep"
